# Screen Specification

## Main menu
Reference: `references/01_main_menu.png`.
- Large hero ship.
- Primary Start Run button.
- Daily Challenge secondary button.
- Ships and Upgrades shortcuts.
- Compact currencies and settings in the top safe area.
- No more than one promotional event panel.

## Stage select
Reference: `references/02_stage_select.png`.
- Connected planet nodes.
- Current stage is strongly highlighted.
- Mission detail panel includes enemies, objective, recommended power, rewards, and Launch.
- Locked stages remain visually understandable without clutter.

## Hangar
Reference: `references/03_hangar.png`.
- Player ship is the visual focus.
- Upgrade rows: weapon, shield, engine, drones, ultimate.
- Show current level, next benefit, and cost.
- Alternative ship thumbnails remain secondary.

## Gameplay HUD
Reference: `references/04_gameplay.png`.
- Score and currency are low priority.
- Wave or boss progress is centered at the top.
- Pause button remains reachable and safe-area compliant.
- Health and shield are visible without occupying the dodge region.
- Ability buttons use large touch targets but modest visual size.

## Upgrade choice
Reference: `references/05_upgrade_choice.png`.
- Combat pauses and darkens slightly.
- Three cards fit without horizontal scrolling.
- Selection feedback includes scale, border intensity, haptic feedback, and sound.
- Descriptions should be one or two short lines in the shipped mobile UI.

## Boss fight
Reference: `references/06_boss_fight.png`.
- Boss scale is dramatic, but collision boundaries remain fair.
- Bullet patterns are bright against a reduced-contrast background.
- Use telegraphs before lasers or screen-crossing attacks.

## Victory
Reference: `references/07_victory.png`.
- Celebrate before presenting numbers.
- Show score, destroyed enemies, combo, time, rewards, and progress.
- Primary next action: Next Sector.
- Secondary action: Upgrade Ship.
