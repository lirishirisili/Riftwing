# Implementation Roadmap

## Phase 0 - Repository and visual sandbox
- Create Godot project.
- Establish portrait viewport, safe areas, folders, theme, and debug menu.
- Build a visual sandbox that displays placeholder player, enemy, bullets, pickups, and background layers.

## Phase 1 - Core movement and shooting
- One-finger movement.
- Auto-fire plasma weapon.
- Object pool for projectiles.
- Screen bounds and pause handling.

## Phase 2 - First enemy loop
- Enemy base component system.
- Scout and Shooter enemies.
- Wave data and spawner.
- Damage, death, pickups, score.

## Phase 3 - Game feel
- Hit flash, recoil, particles, sound, damage numbers, camera shake, haptics.
- Effects quality budget.
- Readability pass on real phone.

## Phase 4 - Roguelite upgrades
- XP collection.
- Level-up pause state.
- Three-card choice UI.
- Plasma, missiles, laser, and drone upgrades.

## Phase 5 - Mini-boss and boss
- Warning sequence.
- Pattern controller.
- First three-pattern boss.
- Victory and failure states.

## Phase 6 - Meta screens
- Main menu.
- Stage map.
- Hangar and permanent upgrades.
- Result screen and local save.

## Phase 7 - Content and balance
- Three stages.
- Six enemies.
- One boss plus one mini-boss.
- Twenty meaningful run upgrades.
- Device testing and accessibility settings.

## Phase 8 - Store readiness
- Android AAB and iOS Xcode export.
- Privacy, analytics, crash reporting, store product setup, achievements, and cloud save.
- Monetization only after retention and playtest feedback.
