# Reference Image Rules

These files are concept references for layout, atmosphere, palette, hierarchy, and effects.

Important: the words `STARFORGE` and `GALAXY RUSH` visible inside some images are obsolete placeholder branding. The game name is `RIFTWING`. Claude must rebuild all labels as real Godot UI text and must never copy the obsolete names into the implementation.

Do not use these full images as in-game textures. Use them beside screenshots of the running game during visual review.
