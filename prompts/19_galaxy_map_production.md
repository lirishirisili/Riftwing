# Milestone 19 — Production Galaxy Map

## Goal

Upgrade the stage-select / galaxy-map screen into a polished production-quality screen.

## Requirements

### Branding

- Use only `RIFTWING`.

### Main layout

Create a production map experience with:

- sector title / map header
- node-based progression path
- highlighted current mission
- mission information panel
- launch CTA
- difficulty presentation if already supported
- bottom or side navigation consistent with the project

### Visual direction

Use:

- deep-space background
- glowing mission lines
- readable planet / node presentation
- locked node presentation
- clear selected-node emphasis

### Map nodes

Nodes must have clear states:

- completed
- current
- unlocked
- locked

Support stars or completion markers if already part of the system.

### Mission panel

The selected mission panel should clearly show:

- mission name
- enemy type / theme
- short objective
- recommended power
- player power
- possible rewards
- first-clear reward if already supported
- launch button

### Readability

- Avoid visual clutter.
- Keep selected mission info readable on mobile.
- Ensure the launch button is obvious.

### Integrity

- Preserve progress saving.
- Preserve launch restrictions for locked stages.

## Acceptance criteria

- The galaxy map no longer looks like a prototype.
- Node progression is easy to understand.
- Selected mission info is clear.
- Launch behavior still works.
- The screen feels visually consistent with the rest of the game.
