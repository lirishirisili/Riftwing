# Milestone 18 — Production Hangar

## Goal

Upgrade the hangar / ship-upgrade screen to a polished production-quality
screen consistent with the references.

## Requirements

### Branding

- Use only `RIFTWING`.
- Never use obsolete reference branding.

### Main composition

Create a hangar screen with:

- central featured ship presentation
- dark sci-fi hangar or holographic bay atmosphere
- readable ship selection column or strip
- production-quality stat and upgrade panels

### Hero ship presentation

The selected ship must feel premium:

- correct scale
- clear silhouette
- engine glow or energy presentation
- subtle idle motion
- optional holographic scan / platform effect

### UI sections

Support and visually improve:

- ship selection list
- locked / unlocked state
- equipped state
- stats summary
- upgrade rows
- upgrade cost presentation
- total power presentation
- bottom navigation or back navigation as already established by the project

### Upgrade rows

Each upgrade row should include:

- icon
- name
- level
- progress or tier state
- stat bonus preview
- upgrade action button

Rows must feel consistent and readable.

### Data-driven integrity

- Do not break the existing upgrade logic.
- Preserve saving and loading.
- Preserve locked-ship behavior.

### Visual style

Use:

- blue / cyan framework
- purple accents
- orange highlight where appropriate
- clean spacing
- controlled glow

## Acceptance criteria

- The hangar feels like a polished mid-core mobile screen.
- The selected ship presentation is impressive.
- Upgrade information is clear.
- Existing upgrade and save systems still work.
- The screen remains readable on a phone.
