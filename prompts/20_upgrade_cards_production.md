# Milestone 20 — Production Upgrade Choice Cards

## Goal

Upgrade the in-run level-up / upgrade-choice overlay to a polished,
rewarding production-quality experience.

## Requirements

### Branding and text

- Use only `RIFTWING`.
- Keep text concise and readable.

### Core experience

The upgrade-choice moment should feel exciting and high-value.

Improve:

- overlay presentation
- card frames
- rarity treatment
- icon / illustration presentation
- title hierarchy
- description readability
- selection feedback
- reroll presentation if supported

### Layout

The overlay must:

- dim gameplay without hiding the context entirely
- keep the player aware that gameplay is paused
- center the three upgrade choices clearly
- remain readable on tall portrait screens

### Card system

Support a visually clear rarity language, for example:

- rare = blue
- epic = purple
- legendary = gold

Cards should include:

- rarity label
- upgrade name
- icon / art
- concise description
- optional category emblem

### Feedback

Add or improve:

- card hover/focus state where relevant
- tap press feedback
- choice confirmation feedback
- reroll feedback

### Integrity

- Do not break the underlying upgrade logic.
- Do not alter the data-driven upgrade system unnecessarily.

## Acceptance criteria

- The upgrade-choice overlay feels rewarding and visually attractive.
- Card rarity is immediately understandable.
- Text is readable on a phone.
- Gameplay resumes correctly after selection.
- The system remains stable.
