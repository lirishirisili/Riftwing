# Milestone 17 — Production Main Menu

## Goal

Redesign the main menu so it feels like a polished production screen
in the style of the concept references.

Do not add monetization or online systems.

## Current problems to solve

- The current menu is visually empty or generic.
- Buttons look like plain prototype rectangles.
- The hero presentation is not cinematic.
- The screen lacks hierarchy and atmosphere.
- The debug overlay may interfere with the presentation.

## Requirements

### Branding

- Use `RIFTWING` as the main visible brand.
- Use the store-friendly subtitle `Space Survivor` only if it improves the layout.
- Never show `Starforge` or `Galaxy Rush`.

### Hero composition

Create a strong main-menu composition containing:

- large featured player ship
- polished deep-space background
- distant enemies or event atmosphere
- subtle depth, glow, and motion

The hero ship must not be excessively blurred.

### Layout

The main menu should include:

- title / brand area
- optional player profile / level area
- start run primary CTA
- daily challenge secondary CTA
- ships / upgrades navigation buttons
- settings access
- optional event banner

The primary CTA must clearly dominate visually.

### Visual direction

Use:

- blue / cyan tech framing
- purple accent color
- clean sci-fi typography
- luminous but controlled glow
- layered background depth

### Buttons

Buttons must look like production UI elements, not placeholder blocks.

Create reusable button styles for:

- primary action
- secondary action
- tertiary nav action

### Safe areas

- Support tall Android portrait screens.
- Ensure title and primary button are not clipped.

### Motion and atmosphere

Add subtle animation where appropriate:

- ship idle drift or hover
- slow parallax background
- event banner ambient motion
- button glow or pulse

Keep it tasteful and lightweight.

## Acceptance criteria

- The main menu feels like a real game menu, not a prototype.
- The ship is clear and visually impressive.
- The start button is obvious and attractive.
- Visual hierarchy is strong.
- Navigation remains functional.
- The menu works well on a phone.
