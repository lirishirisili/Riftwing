# Milestone 21 — Production Results Screen

## Goal

Upgrade the victory / defeat / results screen into a production-quality summary screen.

## Requirements

### Branding

- Use only `RIFTWING`.

### Presentation

Create a polished results screen with:

- strong outcome headline (Victory / Defeat / Mission Complete)
- featured ship or emblem presentation
- readable run statistics
- rewards display
- next action buttons

### Statistics

Show and visually organize relevant run stats already supported by the project, such as:

- score
- enemies destroyed
- best combo
- survival time
- accuracy
- boss defeated or sector clear context if supported

### Rewards

Visually improve reward presentation for:

- coins / currency
- crystals or premium materials
- crates / bonus items if supported
- first-clear bonus if applicable

### Actions

Support existing navigation such as:

- next sector
- replay
- return to menu
- upgrade ship

Make the most likely next action visually dominant.

### Visual direction

- celebratory atmosphere on victory
- clean, readable information grouping
- premium badge / emblem treatment if applicable
- not overly cluttered

### Integrity

- Do not grant duplicate rewards.
- Preserve existing result calculation logic.

## Acceptance criteria

- The results screen feels polished and rewarding.
- Stats and rewards are easy to read.
- The next action is obvious.
- Existing reward logic still works correctly.
